BOUNTY HUNTER: BLACK DAWN - unofficial PC port
==============================================

To play: run BountyHunter.exe in this folder.
The game starts full screen. Alt+Enter switches between full screen and a window.
Saves are in %USERPROFILE%\AppData\LocalLow\Freyr\Bounty Hunter Black Dawn


KEYS
----
Move ............................. W A S D (or arrow keys)
Run .............................. hold left Shift
Look / aim ....................... mouse
Shoot ............................ left mouse button (or left Ctrl)
Aim / zoom ....................... right mouse button
Reload ........................... R
Switch weapon .................... 1, 2, 3, 4
Jump ............................. Space
Grenade .......................... G
Melee ............................ V
Power 1 / 2 ...................... F / C
Interact ......................... E  (talk to the NPC you aim at, open chests, pick up items, advance dialog)

Backpack ......................... I
Map .............................. M
Minimap (show/hide) .............. Tab
Quests ........................... Q  (or U)
Achievements ..................... Y
Skill tree ....................... K
Options / pause .................. O, or Esc in combat
Close a menu ..................... Esc (or Q in quests, M in the map)

Use the mouse on the HUD ......... hold left Alt to free the cursor, then click
                                   (HUD icons, tutorial steps, NPCs)

Post-processing on/off ........... F9  (the remaster's ambient occlusion, bloom and color)

Gold and mithril: the in-game store hands out mithril packs for free; trade mithril for gold in its gold tab.
